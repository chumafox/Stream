Маршрут звука без дублирования микрофона

  1. 1
    Установите VB-CABLE

    После установки перезапустите браузер и OBS. В списке выхода выберите CABLE Input.

  2. 2
    Добавьте источник в OBS

    Источники → Захват входного аудиопотока → устройство CABLE Output.

  3. 3
    Отключите русский микрофон в микшере

    Если в эфире должна быть только китайская речь, выключите дорожку исходного микрофона. Оставьте её только для общения с русскими зрителями при необходимости.
