# StreamBridge RU → 中文

Локальный сервис для русскоязычного стримера: вы говорите в микрофон по-русски, а в OBS поступает китайская речь. Сервис использует **Qwen 3.8 LiveTranslate**, автоматически распознаёт русский язык, переводит на китайский и может сохранять тембр вашего голоса.

> Это не reverse proxy мобильного Doubao. Проект использует документированный Alibaba Cloud Model Studio API, потому что нужная связка «русский → китайский + voice cloning» поддерживается Qwen LiveTranslate.

## Возможности

- Потоковый микрофонный ввод: **PCM16, 16 кГц, моно**.
- Китайская озвучка: **PCM16, 24 кГц**, с буферизацией против разрывов.
- Клонирование тембра один раз на сессию (`once`) для сольного стрима.
- Режим `always` для нескольких говорящих или стандартный голос `Tina`.
- Выбор микрофона и устройства воспроизведения прямо в панели.
- Маршрут китайского звука в OBS через **VB-CABLE**.
- Русская и китайская расшифровка, уровни сигнала, состояние буфера и token usage.
- Пользовательский словарь вида `русский термин=中文翻译`.
- Ключ API хранится на локальном сервере, а не в `localStorage` браузера.
- Сервер принудительно запускается только на `127.0.0.1` / `localhost`.

## Что понадобится

1. **Windows 10/11**, актуальный Chrome или Edge.
2. **Python 3.11+**: <https://www.python.org/downloads/>. При установке включите `Add python.exe to PATH`.
3. **VB-CABLE**: <https://vb-audio.com/Cable/>. Установите драйвер и перезагрузите Windows.
4. Аккаунт **Alibaba Cloud Model Studio**, доступ к модели `qwen3.8-livetranslate-flash-realtime` и API key:
   - международный регион: <https://modelstudio.console.alibabacloud.com/>;
   - материковый Китай: <https://bailian.console.aliyun.com/>.
5. Платный баланс/доступная квота. Перевод и генерация аудио тарифицируются Alibaba Cloud.

## Быстрый запуск на Windows

1. Скачайте репозиторий или выполните:

   ```powershell
   git clone https://github.com/chumafox/Stream.git
   cd Stream
   ```

2. Дважды нажмите **`start.bat`**. При первом запуске скрипт создаст `.venv` и установит зависимости.
3. Откроется `http://127.0.0.1:8765`. Нажмите **«Настройки API»**.
4. Вставьте ключ, выберите регион его создания и нажмите **«Сохранить и проверить»**.
5. Выберите свой микрофон и выход **`CABLE Input (VB-Audio Virtual Cable)`**.
6. Нажмите **«Начать перевод»** и разрешите браузеру использовать микрофон.

Ключ, введённый через панель, живёт только в памяти сервера. После перезапуска его нужно ввести снова либо один раз задать в `.env`.

### Постоянное хранение ключа

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
DASHSCOPE_API_KEY=sk-ваш-ключ
DASHSCOPE_REGION=intl
DASHSCOPE_WORKSPACE_ID=
DASHSCOPE_MODEL=qwen3.8-livetranslate-flash-realtime
```

- `intl` — Сингапур/международный кабинет.
- `mainland` — Пекин/китайский кабинет.
- `DASHSCOPE_WORKSPACE_ID` заполняйте, если ваш аккаунт использует выделенный endpoint Workspace. Если пусто, применяется стандартный региональный endpoint.
- `.env` включён в `.gitignore` и не отправляется в GitHub.

## Настройка OBS

1. В панели StreamBridge выберите выход **CABLE Input**.
2. В OBS откройте **Источники → + → Захват входного аудиопотока**.
3. Выберите устройство **CABLE Output (VB-Audio Virtual Cable)**.
4. В микшере OBS выключите исходный микрофон, если зрители должны слышать **только китайскую речь**.
5. Сделайте короткую тестовую фразу и проверьте уровень `CABLE Output`. Громкость китайского канала регулируется в StreamBridge и/или OBS.

```text
Русский микрофон
      │
      ▼
Chrome/Edge → локальный FastAPI → Qwen LiveTranslate WebSocket
                                      │
                                      ▼
                           китайская речь PCM 24 кГц
                                      │
                                      ▼
                              CABLE Input
                                      │
                                      ▼
                         OBS: источник CABLE Output
```

**Не добавляйте один и тот же кабель одновременно как источник и как мониторинговое устройство** — это может создать петлю или эхо.

## Как вести эфир

- Говорите короткими фразами и оставляйте естественные паузы.
- Для одного ведущего оставьте режим **«Клонировать один раз»**. Начало первой речи используется для извлечения тембра.
- При нескольких людях у одного микрофона выберите **«Отслеживать голос»**.
- Имена, никнеймы и названия игр заранее добавьте в словарь.
- Дождитесь китайской озвучки перед следующей фразой. Это последовательный перевод, не нулевая задержка.
- При нажатии **«Остановить перевод»** сервис перестаёт принимать микрофон, отправляет `session.finish` и доигрывает последнюю фразу. Повторное нажатие останавливает всё немедленно.

Заявленная задержка модели — от нескольких секунд; фактическое время зависит от длины фразы, сети, региона и нагрузки. До реального эфира обязательно сделайте приватный тест.

## Решение проблем

| Симптом | Что проверить |
|---|---|
| `HTTP 401` | Ключ и регион должны принадлежать одному кабинету. Попробуйте другой регион и проверьте Workspace ID. |
| `Access denied` / `403` | Откройте доступ именно к `qwen3.8-livetranslate-flash-realtime`; проверьте баланс и квоту. |
| Нет `CABLE Input` в списке | Перезагрузитесь после установки VB-CABLE, затем перезапустите Chrome/Edge. Нажмите «Обновить список устройств». |
| В OBS тишина | В StreamBridge должен быть выбран `CABLE Input`, а в OBS источник — `CABLE Output`. Проверьте, не выключена ли дорожка в микшере. |
| Слышен русский голос | Отключите исходный микрофон в микшере OBS и мониторинг этого микрофона в Windows. |
| Звук прерывается | Используйте проводной интернет, закройте лишние аудиоприложения, говорите короче. Небольшой буфер после паузы — нормальная работа плеера. |
| Китайский текст есть, аудио нет | Проверьте, что в настройках не выбрано «Без клонирования» с недоступным голосом, затем проверьте выход и доступ к audio output модели. |
| Неправильные имена | Добавьте соответствия в «Словарь стрима» и перезапустите сессию. |

## Ручной запуск и разработка

```bash
python3 -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements-dev.txt
python run.py --no-browser
pytest
```

Сервер не принимает внешний `--host`: это намеренное ограничение, чтобы не опубликовать ключ и микрофонный прокси в локальной сети или интернете.

### Структура

```text
app/config.py                 настройки и endpoint региона/Workspace
app/livetranslate.py          Qwen WebSocket protocol, session и события
app/server.py                 локальный FastAPI + браузерный WebSocket
static/app.js                 состояние панели, устройства и PCM-потоки
static/pcm-capture-worklet.js захват/ресемплинг 16 кГц
static/pcm-playback-worklet.js буферизованный PCM-плеер 24 кГц
tests/                        тесты протокола, событий и локального API
```
